# Wireless sensor handover — internal example

Fictional customer: Straits IoT Pte Ltd. Jurisdiction: Singapore.
Suggested skill: Electronics & telecoms.

For this customer's Bluetooth sensor shipments, obtain the supplier's model-specific technical specification and reconcile the model identifier with the commercial invoice and packing list. Keep the evidence beside the declaration draft.

Record the actual validity dates shown on any applicable supporting authorisation. If an expiry falls before the planned shipment, request updated evidence and refer the case to the senior reviewer. A reference number alone is insufficient evidence that an authorisation is current or applicable.

Do not promise clearance or delivery until the assigned reviewer has confirmed the case's outstanding documents and receiving arrangements. Any promised timing must reflect the evidence available in that case.

These are illustrative internal operating notes, not a statement of IMDA or Singapore Customs law. Verify official requirements for the actual product before applying this note. Import this document as pending knowledge and review it before publication.
