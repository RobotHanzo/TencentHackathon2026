# 訪談整理：（報關業主管）

背景：她在報關公司帶新人、審單。報關不是不動產，但她遇到的困擾和這次題目幾乎一樣，可以拿來證明這個方案適用其他產業（可擴展性）。逐字稿是語音辨識的，有些字錯了，例如「稅者」應該是「稅則」、「正過期」應該是「證過期」，下面已經改正。

## 五個關鍵發現

**1. 問題不是缺知識，是當下想不起來要查（最重要）**
- 她早就把特殊案件分類整理好了（輻射類、食品類），電腦也會跳出法規提示。新人還是會出錯，連她自己也會漏。
- 原話：「寫好了也是有時候沒注意到啊，有時候我也沒注意到。」
- 原話：「沒有那個經驗，就不會有那個意識要去注意到那件事情。」
- **對設計的意義**：做成「新人來問 AI」的問答資料庫不夠，因為新人根本不知道要問。處理小卡必須在打單的當下主動檢查、指名提醒。通用的跳窗提示已經證明沒用，大家會直接略過。

**2. 很適合當 demo 的真實事件**
- 進口車用遙控器需要 NCC 許可證。號碼打對了，但許可證已經過期。
- 海關不會退回錯單，會直接收單，結果貨物被卡住，只能放棄或退運，造成金錢損失。
- 這次連資深人員也沒發現，她自己說只注意到號碼有打、打對而已。
- **對設計的意義**：AI 的角色是第二道檢查，不是取代人。「許可證效期」這種規則可以寫成機器檢查。

**3. 老手審單的那一刻，就是最好的記錄點**
- 現在的流程：新人打完單，印出來交給她，她改完退回，新人修改後再給她看，打勾才送出。
- 原話：「他打錯我修改，他打錯了修改，然後也不知道有沒有吸收進去。」
- 她擔心導入系統會讓老手工作變多。
- **對設計的意義**：不要另外請老手寫紀錄。她每一次修改新人的單子，系統就自動記成一筆「錯誤 → 正確做法 → 原因」。這樣老手零額外負擔，同時也能追蹤新人是否重複犯同一個錯。

**4. 她不會取消人工審核，但願意縮短帶新人的時間**
- 原話：「沒有資深的在後面看著，我覺得也是不太放心。」
- 她把錯誤的原因歸為人為疏失，覺得一定要有第二個人看過。
- 但如果帶新人的時間能縮短，她說「當然是好啊」。
- **對設計的意義**：AI 先預審一次，把明顯的錯先擋下來，減少她的修改次數；最後送出的決定權還是留在人手上。

**5. 授權是逐步放手，依據是錯誤率**
- 剛開始每張單都全審，順利幾次後就改成快速看過，再之後完全放手。
- 新人約半個月到一個月學會打單，之後再慢慢教各種特殊規定。
- 她判斷新人能不能獨立，看的是錯誤率高不高、清關順不順利。
- **對設計的意義**：授權等級不只綁在處理小卡上，也要綁在每個人身上。系統依新人的錯誤率，自動建議從「全審」調降成「抽審」。

## 次要發現
- 每天遇到的事情大同小異，所以知識可以重複使用的比例很高。
- 新人卡住的類型不只一種：有人是不知道要做什麼，有人是不敢問，有人是自己做錯了才被改，看個性而定。
- 她認為新人要自己做筆記才記得住，所以系統可以讓新人在處理小卡上加個人筆記。
- 她覺得交接最難的是熟悉度，以及和客戶聯絡時的口條和應對。這屬於軟技能，系統很難處理，簡報應該明說這不在範圍內。

## 假設驗證

| 假設 | 結果 |
|---|---|
| 只靠 SOP 不夠 | 符合，專業法規要有老手帶 |
| 資深員工離開影響大 | 符合，前面的人沒注意到，要靠資深的人攔截 |
| 交接時有些東西傳不下去 | 部分符合。她說資料整理得好，交接就不難；難的是意識和熟悉度 |
| 老手願意配合 | 有條件。只要不增加工作量就願意，她自己本來就在做筆記 |
| 可以完全交給 AI | 不符合，人工審核一定要保留 |

## 對系統設計的三個修改
1. **捕捉點改到審核環節**：老手的修改紀錄就是知識來源。原本的影子模式（比對預測和實際做法）保留，作為第二個來源。
2. **從被動問答改成主動檢查**：處理小卡在作業當下就逐條檢查，例如許可證效期、是否需要合格證，而不是等新人來問。
3. **授權跟著人走**：每個新人有自己的錯誤率，系統依此建議調整審核強度。

## 放到 Keppel 情境的對應

| 報關 | 設施管理 |
|---|---|
| 許可證過期 | 電梯檢驗證、動火許可、設備保固過期 |
| 審單退回修改 | 主管審核工單、作業許可 |
| 依錯誤率逐步放手 | 新技師值班權限分級 |
